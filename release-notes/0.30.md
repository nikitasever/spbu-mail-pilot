# 0.30 · Фоновые уведомления и свободные адресаты

- Добавлена независимая фоновая проверка новых писем через `AlarmManager`, чтобы уведомления приходили при закрытом приложении.
- Расписание восстанавливается после перезагрузки телефона и обновления приложения; параллельные проверки защищены от дублей.
- В поле «Кому» можно отправлять письмо на любой корректный полный адрес, даже если его нет в контактах.
- Сохранены выбор иконки СПбГУ, подсказки адресатов и прогресс вложений из 0.29.
