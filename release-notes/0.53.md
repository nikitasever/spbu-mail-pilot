# 0.53 — виджет рабочей почты

- Виджет на рабочем столе: текущий ящик, число непрочитанных во входящих и время последней успешной проверки.
- Ближайшие сохранённые события и личные задачи на семь дней. Нажатие открывает почту или календарь, сохраняя набранный черновик.
- Светлая/тёмная тема и изменение размера. При крупном шрифте список сокращается, чтобы действия оставались доступны.

Добавление: удерживайте свободное место рабочего стола → «Виджеты» → «Рабочая почта». Содержимое будет видно на рабочем столе. Счётчик обновляется при открытии входящих и существующей фоновой проверке; календарь использует уже сохранённые события. При задержках Android время проверки помогает определить актуальность.

Проверены сборка, модель дат, переходы и сохранение черновика. Отображение/обновление на конкретном лаунчере требует проверки на телефоне.
