предзагрузка, MIME href и исходные заголовки. Не переписывать их повторно только из-за старого обзора.

- [ ] Проверить жизненный цикл поиска: успех/ошибка/отмена, пустые страницы с hasMore, смена критериев,
  одинаковый текст и разные фильтры, переход в письмо и назад, отсутствие потери фокуса/позиции.
- [ ] Проверить модель массового выбора: owner/folder/criteria scope, смена категории/папки, частичный
  серверный успех, неопределённый результат, фон и блокировка, отсутствие невидимых выбранных строк.
- [ ] Проверить пароли: CAS для активного и другого ящика, сохранность SMTP и activeId, фон во время
  проверки, отсутствие секретов в сохранённом UI-состоянии/диагностике.
- [ ] Проверить календарь: первый запуск picker без открытия календаря, discovery/подключение/удаление,

- [ ] Проверить общее хранилище: параллельные обновления из двух UI, сохранность свежего Seen/страниц,

- [ ] Проверить реальные MIME-пути для href/заголовков, лимиты/усечение и предупреждения,

## Задание другой модели

Брать последний коммит этой ветки как базу. Выбрать один блок выше и работать реальным git diff,
а не заменять целые файлы из старых архивов. Не удалять проверки/функции и не повышать версию.
Нужны команды и фактические результаты. UI/ядро/тесты проверять совместно: успешная сборка одного
Compose APK не доказывает совместимость с прежним build.py. APK, реальная почта/контакты и внешние
агенты без отдельного запроса не нужны. Сначала завершить компиляционную проверку, затем паритет.
