## Как раздать задачи другой модели

После восстановления дать точный base SHA, UX-CONTRACT.md, DESIGN.md, нужные исходники и тесты.
Пакеты: A — поиск; B — календарь; C — аккаунты/почтовые действия; D — файлы/финальный паритет.
Разные пакеты могут затрагивать ComposeInboxActivity/NativeInboxModel: согласовать владение файлами,
иначе интегрировать последовательно. Входные условия: обычный UTF-8 unified diff; без откатов прежних
исправлений, удаления тестов, APK/версий/реальной почты; приложить команды и фактические результаты.
Каждый пакет принимается отдельно после проверки, а документация обновляется по итоговому поведению.
