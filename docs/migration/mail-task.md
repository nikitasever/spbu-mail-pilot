# Создание задачи из письма

Legacy: ui/app.mjs, действие mail-task. Пустые название/срок/комментарий,
обычный приоритет, reminder auto, done false, связь с выбранным письмом.
Compose переносит создание в существующий NativeWorkspaceModel/общий state.
Сохранение выполняется только кнопкой; отмена возвращает к открытому письму.
Папка/фильтр/позиция чтения остаются в исходном NativeInboxModel.

Ссылка проверяет account/folder/UID/UIDVALIDITY; сохраняются только ссылка и
subject/sender/date для подписи. Тело, Bcc, файлы и прочие заголовки не копируются.
Это намеренное сокращение legacy-снимка, обратный переход использует точную ссылку.
Вложенное создание из временного linked-reader пока недоступно.
Отключение задач в настройках блокирует форму и сохранение. Ошибка записи оставляет
редактор открытым. Поворот сохраняет форму в ViewModel; process death её не сохраняет.

Проверки: NativeMailLinksTest — пустые поля/настройки, область аккаунта,
Unicode-папка, исключение лишних данных и неизменность оригинала. Paparazzi
mailTaskEditor — реальный Compose-экран и закрытие/очистка временного маршрута.
Сохранение использует ранее проверенный record CAS NativeWorkspace.change.
Сравнение старого/нового полного UI не запускалось; равенство всего клиента не заявляется.
Android-диск, реальные касания, IMAP и уведомления требуют проверки на устройстве.
