# Событие из письма и выбор даты/времени

Legacy: ui/app.mjs startMailEvent/saveMailEvent/mailCreatedEvent,
ui/mail/date-hint.mjs. Нативная реализация: NativeMailEvents, NativeWorkspaceModel,
WorkspaceDateTime и экран чтения Compose.

- Меню письма открывает форму локального события. Тема подставляется как название.
  Один созданный из письма event определяется по папке/UIDVALIDITY/UID.
  Повторное действие открывает ту же запись, неоднозначные дубликаты отклоняются.
- Распознаются дата ДД.ММ.ГГГГ ЧЧ:ММ и однозначные сегодня/завтра/послезавтра
  с единственным временем ЧЧ:ММ или ЧЧ-ММ. Относительная дата считается от даты
  письма по Москве. Прошедшая/неверная/неоднозначная подсказка не показывается.
  В нативном reader используется тема; парсинг preview не включён в UI.
- Без подсказки форма предлагает сегодняшний день Москвы и пустое время.
  Ничего не сохраняется автоматически. Перед сохранением дату можно исправить.
- Event и eventMailLinks изменяются в одном свежем JSON под общим state lock,
  одним commit. Record CAS и проверка createdFromMail защищают от устаревшего
  редактирования и параллельного создания. Максимум 500 связей, как в legacy.
  При ошибке исходный JSON не меняется и форма остаётся открытой.
- Источник содержит точную account/folder/UID/UIDVALIDITY-ссылку и подпись,
  без тела/получателей/вложений. Другие записи, ссылки и неизвестные поля сохраняются.
  Общий CRUD обновляет метаданные связей и убирает их при удалении события.
- Сохранение/отмена возвращают к письму. Из уже сохранённой неизменённой формы
  доступен переход в календарь на дату события; при несохранённых изменениях
  этот переход недоступен. Временный linked-reader пока не открывает новые формы.
- В задачах/событиях доступны Material DatePicker и 24-часовой TimeInput.
  Дата хранится как UTC calendar label, время — как московское wall time;
  зона телефона не сдвигает выбранный день. Ручной ввод сохранён. Диапазон 1970–2100.
  У задачи можно убрать срок, у события дата обязательна.

Отличия от legacy: после save остаётся письмо, а не принудительный уход в календарь;
переход в календарь доступен явно. Создание связи с произвольным существующим
серверным/локальным событием и удаление отдельной связи ещё не перенесены.
