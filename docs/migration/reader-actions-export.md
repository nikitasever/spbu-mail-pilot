# Действия чтения и экспорт файлов Compose

Текст письма выделяется стандартными средствами Android. Поделиться текстом использует прежний ShareActions и ограничение 140000 знаков; превышение не обрезается молча. Система предлагает выбор приложения, а сообщение не считается отправленным. Видимые абсолютные HTTP/HTTPS ссылки и российские номера распознаются без сети. URI с другими схемами, user-info, управляющими/форматирующими знаками отклоняются; набор номера использует ACTION_DIAL, не вызов. Ограничение поиска — первые 200000 знаков и по 20 результатов. Скрытые href HTML-частей пока не переносятся. Копирование/внешние действия проверяют актуальные аккаунт, письмо, foreground и AppLock.

Вложения можно открыть, передать выбранному приложению или сохранить; оригинал .eml и все вложения текущего письма сохраняются в явно выбранную SAF-папку. NativeExportPlan фиксирует точные owner/folder/UID/UIDVALIDITY/MIME paths, не содержит пароль и не угадывает отсутствующие ссылки. После выбора папки/разблокировки читаются свежие credentials того же owner. Повторный запуск передачи автоматом не выполняется.

Используется существующий BulkAttachments + SafAttachmentDestination: последовательные скачивания, до 500 файлов по 100 МиБ, .part и финальное переименование, отсутствие перезаписи, прогресс байтов/файлов, частичные результаты. Временные приватные копии disposable; неподтверждённые документы удаляются по возможности провайдера. При отмене готовые файлы остаются. Фон отменяет уже запущенную передачу; выбор папки и ожидание разблокировки не запускают сеть в фоне. Блокирующий IMAP закрывается через NativeReadGate вне UI-потока.

У запроса системного выбора есть владелец NativeExportPicker. Поздний ответ отменённой операции не прикрепляется к новому плану. Ключ ActivityResultRegistry уникален для retained ViewModel: сохраняется при повороте, меняется после гибели процесса. План/URI/credentials не записываются в SavedStateHandle, старый запрос не восстанавливает передачу автоматически. Глобальная pending-навигация ждёт закрытия диалога экспорта.

Проверки: bash native-ui/test-reader-actions.sh (ссылки/номера, планы/границы файлов, изоляция выбора папки, штатный BulkAttachmentsTest на 50 последовательных файлах и частичных отказах); Kotlin/Java compilation; 18 JUnit проверок ReaderDetails/ThreadNavigation/InboxThreads. Реальные SAF-провайдеры, chooser, процесс/поворот, AppLock и IMAP требуют проверки на устройстве. APK и рендеры не создавались.
