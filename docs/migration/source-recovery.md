## Как импортировать

- Распаковать снимок в отдельный каталог, проверить состав/хеш; не затирать checkout слепо.
- Сравнить с main, сохранить новую историю GitHub и действующие лицензии/CI.
- Проверить `native-ui`, Gradle wrapper, Java/Kotlin, tests, docs/migration; пропущенные зависимости
  либо восстановить штатно по lock-файлам, либо явно перечислить, не объявляя сборку готовой.
- Не переносить `local.properties`, `.gradle`, `.kotlin`, `build`, `node_modules`, ключи, приватные данные.
  Нужные зависимости `lib` учитывать согласно политике проекта, не отключать `.gitignore` целиком.
- Проверить SAF-строгое UTF-8-декодирование, отмену и owner/session; не заменять их исходным package2.
- Системный импорт должен сохранять несколько email, явно показывать лимиты/невалидные записи,
  поддерживать выбор и CAS очистки recipientBook.
- Создать коммит полной восстановленной базы и записать его SHA для следующих исполнителей.
