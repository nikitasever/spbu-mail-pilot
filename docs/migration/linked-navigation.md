# Переходы к связанным письмам в Compose

Задача показывает «Открыть исходное письмо», событие — существующие связанные
письма. Источники прежнего поведения: ui/app.mjs task-source (675), eventLinkKey /
calendar-linked-mail (453,647). Ключ сервера — [calendarId,id], локальный — local:<id>.
Новые связи и их удаление этим блоком не создаются; CalDAV и общие события не меняются.

NativeMailLinks проверяет owner, строковые folder/uid/validity, отказ при явно чужом
account. Только отсутствующая folder получает старый INBOX default; пустая/повреждённая
ссылка отвергается. Поиск письма по теме/адресу вместо точного UID не выполняется.
Для событий выбирается точная сохранённая JSON-связь; повторяющиеся id не открывают
другое письмо, устаревшие/удалённые связи не принимаются. Метаданные не изменяются.

NativeInboxModel держит исходный InboxState и отдельную прокрутку временного reader
в памяти. Чтение использует прежний BODY.PEEK/cache и точный UIDVALIDITY. Back
инвалидирует запрос и возвращает исходный список/чтение, папку, фильтр и поиск;
Activity снова показывает сохранившийся экран задачи/календаря. Compose holder
сохраняет его прокрутку. Входящее read/unread отражается по session Seen overlays.
При обычном фоне истекает и исходный online pager; после возврата нужен явный refresh.

Улучшение относительно прежнего перехода: возвращение именно к источнику, без
изменения выбранной почтовой папки. Временная связь/текст/offset не сохраняются в
SavedStateHandle; исходный route и позиции не заменяются. После process death
восстанавливается доступная прежняя почта, временный переход не обещает восстановления.

Проверка: native-ui/test-mail-links.sh (3 host-набора, 2 затронутых WebView-теста).
Дополнительно linkedReturn выполняет настоящий NativeInboxModel.backToList/pause в
Layoutlib: возвращает INBOX/query/filter/rows, сохраняет offset/route и помечает
исходный pager истёкшим. Два Paparazzi-снимка — реальные экраны задачи и календаря.
AppLock, реальные IMAP/Android lifecycle/жесты и устройство этим не проверены.
