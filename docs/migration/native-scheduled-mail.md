# Отложенная отправка Compose

16 октября 2026. Редактор → «По расписанию»; список → «Ещё → По расписанию».
Дата/время по Москве с существующими Material date/time controls и проверкой будущего
момента. Явное подтверждение сохраняет задание в существующую ScheduledMail, без
второго планировщика и без сетевой отправки в UI-потоке. Письма отправляет прежний
фоновый механизм при наличии сети. Точное время Android не гарантируется.

Нативный черновик проходит durable EDITING → SCHEDULING → SCHEDULED. Маркер пишется
до создания задания; ошибка после вставки очереди оставляет нередактируемый маркер.
При повторном открытии редактор сверяет точный source id с очередью под общим
NativeDraftStore.gate. Недоступная очередь не разрешает повтор. Отсутствующее задание
позволяет вернуть EDITING; существующее (включая историю отправленного/отменённого)
закрывает черновик как SCHEDULED. NativeSendTransaction не принимает эти состояния.

ScheduledMail.createFrom принимает проверенную директорию нативных вложений и
копирует файлы в прежний durable queue snapshot. Исходные нативные файлы остаются
до закрытия SCHEDULED. Прежний create по-прежнему использует outgoing и удаляет
исходные файлы после успешного сохранения. Ошибка регистрации Android scheduler
показывается пользователю; автоматического повторного создания задания нет.

Экран очереди показывает до 150 записей текущего аккаунта, статусы, предупреждения
и следующую попытку. Отмена требует подтверждения; transmitting отменить нельзя,
uncertain не отправляется автоматически повторно. UI не запускает доставку сам.
После отмены письмо можно явно вернуть в нативный редактор. Существующий другой
черновик не перезаписывается. Вложения копируются с проверкой размера и fsync;
queue snapshot подтверждается/освобождается только после шифрованного native commit.
При частичной ошибке остаётся очередь или уже записанный нативный черновик.
Повтор возврата того же id не заменяет правки нативного черновика.

Фон закрывает неподтверждённые диалоги и инвалидирует UI-ответы. Уже подтверждённая
запись задания/отмена/восстановление может завершиться в фоне; это не обещание отмены
дисковой операции при onPause. Аккаунт и AppLock проверяются перед операцией.
Пароли не записываются в очередь. Неизвестный результат прежней попытки требует
проверки получателя перед новой ручной отправкой.

Проверки: native-ui/test-scheduled.sh — сбои до/после queue commit, повтор, сверка,
недоступная очередь, сериализация статуса, московское время, перенос метаданных,
защита snapshot-файлов. native-ui/test-compose.sh — регрессии редактора/доставки.
test-scheduled-send.cjs — прежний сценарий. Kotlin/Java compile и выбранные JUnit.
Живые SMTP/JobScheduler/SQLite+Keystore/SAF/IME/AppLock на устройстве не проверялись.
APK и рендеры отложены. Серверные и несколько черновиков остаются следующим блоком.
