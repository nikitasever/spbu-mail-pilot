Следующий независимый блок контактов — системная адресная книга и история адресов. Репозиторий: /workspace/spbu-mail-pilot.
Это действующее приложение, требуется закончить перенос функций прежнего
WebView-клиента, сохранив Java-ядро и пользовательские данные.

## Указания владельца

- Действовать самостоятельно в рамках переноса, не останавливаться на вопросах
  «продолжать?». Беречь лимиты: небольшие законченные задачи, целевые проверки,
  без повторных обзоров всего кода и массового запуска агентов.
- Не собирать APK, не выпускать релизы и не делать рендеры/скриншоты до завершения
  переноса. Kotlin/Java compile и выбранные host/JUnit-проверки разрешены.
- Сохранить фиолетовую тему. Не заменять приложение демонстрационным HTML.
- ПК-версию пока не делать. Основная цель — Android APK.
- Не запрашивать и не использовать реальные пароли для тестов. Не отправлять
  реальные письма. Не выдавать host-тесты за проверку телефона или сервера.

## Очередь оставшихся работ

1. **Расширенный серверный поиск и фильтры**: перенос UI условий отправитель,
   тема/текст, даты, непрочитанные/вложения; переиспользовать SearchQuery и
   MailReader.smart/существующий протокол. Держать фильтры и cursor одним
   снимком. Отдельно показывать локальный поиск и серверный результат.
   Затем единая точка поиска писем/файлов/контактов/событий с честной областью.
2. **Календарь**: подключение/отключение источников; новые связи письмо↔событие,
   переход задача→событие. Сверить прежние функции серверного редактирования:
   переносить только поддержанные протоколом операции и права, не изобретать их.
3. **Контакты**: импорт файла и системной адресной книги с предпросмотром,
   выбором/дедупликацией; история адресов и её очистка. Не писать в университетский
   справочник. Не запрашивать Android-разрешение до явного действия пользователя.
4. **Оставшиеся почтовые операции**: смена пароля существующего входа,
   управление папками; действия из списка и массовые операции; полные заголовки,
   скрытые HTML-ссылки; preview-предзагрузка; управление произвольным серверным
   оригиналом черновика с точной идентичностью и подтверждением.
5. **Доработка поиска файлов**: общая область по папкам/офлайн-индекс и массовый
   экспорт разных писем, если эти функции есть в прежнем клиенте.
6. **Сверка равенства возможностей**: сопоставить каждое действие прежнего UI
   и Bridge с Compose, исправить неперенесённые ветки и навигацию. Возврат в
   WebView не считать реализацией функции. Не оценивать готовность по числу экранов.
7. **Финальная приёмка**: после переноса — один тестовый APK и проверка на
   телефоне: AppLock/PIN/биометрия/recents, фон/процесс, клавиатура/поворот,
   SAF/просмотрщики, IMAP/SMTP/CalDAV, uncertain-send, очередь и уведомления.
   До этого не менять версию и не публиковать релиз.

Это приоритеты, не обещание точного количества оставшихся функций или срока.
Перед реализацией сверять прежний клиент и актуальный код; старые пункты плана
могут быть уже закрыты. Удалённые серверные операции требуют особенно точной
проверки прав/идентичности, запрета broad expunge и защиты от повторной отправки.

## Конкретная самостоятельная задача другой нейросети

Перенеси в Compose **импорт контактов из файла**, переиспользовав существующий
парсер и локальный CRUD. Сначала найди поддерживаемые форматы в прежнем UI/Java,
не добавляй неподдерживаемые форматы ради галочки. Android SAF → ограниченное
чтение выбранного файла → предпросмотр валидных/невалидных строк и дублей →
явное подтверждение → запись только локальных контактов текущего account.
Сохрани исходные контакты при отмене/ошибке; повтор не должен молча дублировать
данные. Защити уход в фон, AppLock, смену account и устаревшие ответы.

Работай в NativeContactsModel/NativeContactsScreen и связанных чистых политиках.
Не меняй общий ComposeInboxActivity без необходимости; если понадобится точка
интеграции, опиши её отдельным маленьким патчем. Это уменьшит конфликт с основной
работой над поиском. Без APK, релизов и внешних моделей. Верни изменённые файлы,
реально запущенные проверки, ограничения и короткий diff-summary.

## Проверки и честность результата

Для host javac здесь требуется PATH=/workspace/scratch/java-tools:$PATH.
Некоторые test-*.sh не executable: запускай через bash.
Новый блок проверять его профильным скриптом и затронутыми регрессиями, не всем
набором после каждого небольшого изменения. Все исходники дописать до финального
compile, чтобы не гонять его дважды из-за последующих правок.

Текущая команда compile/JUnit (без APK и рендеров):
python /workspace/scratch/run-native-gradle.py -PrenderUi \
 :app:compileDebugKotlin :app:compileDebugJavaWithJavac \
 :app:testDebugUnitTest --tests ru.local.spbumailpilot.NativeFileLibraryPrivacyTest \
 --tests ru.local.spbumailpilot.NativeDraftCollectionPrivacyTest \
 --tests ru.local.spbumailpilot.NativeNavigationTest

-PrenderUi подключает previewTest; эти выбранные JUnit не делают рендеры.
При другой среде адаптировать SDK/JDK/Gradle, не копировать workspace-пути слепо.
