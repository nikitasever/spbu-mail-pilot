## Правила продолжения

1. Сначала вернуть и закоммитить полный исходный Compose-проект. Не начинать новый перенос поверх
   WebView main, иначе получатся две несовместимые реализации.
2. Сохранить существующее Java-ядро, AppLock/FLAG_SECURE, фиолетовую тему и UX-CONTRACT.md.
3. Не применять целиком package3/package4: они отклонены, а не интегрированы.
4. Не удалять тесты, не публиковать APK и не поднимать версию до завершения переноса и общей приёмки.
5. Использовать тестовые данные; не обращаться к реальной почте/контактам и не помещать пароли,
   токены, ключи подписи, кеши и приватную переписку в git.
6. После восстановления вести изменения обычными небольшими git diff с точным base commit.
   Каждому пакету — отдельный коммит и соответствующие целевые проверки.

Push в main сейчас запускает `.github/workflows/android.yml`: сборку и публикацию APK.
Для передачи работ используется отдельная ветка. Изменения в main пока не сливать.
