# ИИ-инструменты редактора Compose

16 октября 2026. Два действия редактора: «Проверить текст» и «Предложить ответ».
Они повторяют прежний сценарий подготовки запроса для внешнего ИИ, без прямого API-вызова Gemini.

Перед предпросмотром сохраняется исходный черновик. Запрос можно редактировать,
скопировать или явно передать через системный выбор приложения. Закрытие изменённого
запроса требует подтверждения; письмо и вложения не заменяются. Отправка почты
остаётся отдельным действием. Отсутствующее приложение обрабатывается как ошибка.

Передаются только видимые тема, текст черновика и, для нового ответа, загруженный
текст исходного письма. Поля To/Cc/Bcc, вложения и ключ Gemini не добавляются.
Проверка текста не включает оригинал. Контекст ответа ограничен 12 000 UTF-16 единиц
с видимым предупреждением; после восстановления отдельного черновика отсутствие
контекста обозначается прямо. Контекст и запрос хранятся только в памяти ViewModel.
Буфер обмена помечается чувствительным, но очистка буфера внешними приложениями
не гарантируется. Текст не включается в диагностический ComposerState.toString().

Разрешение анализа проверяется для текущего аккаунта; непосредственно перед
копированием/chooser повторно проверяются аккаунт, AppLock и foreground.
Уход в фон инвалидирует незавершённую передачу. Ответ старой проверки аккаунта
не изменяет экран после паузы/нового resume. Прямые действия изменения/отправки
черновика заблокированы во время предпросмотра запроса.

Проверки: NativeWritingAiTest (границы, инструкции, Unicode, неизменность текста,
отсутствие скрытого контекста при проверке), NativeWritingAiPrivacyTest (2 JUnit),
регрессии NativeAiPrivacyTest и NativeNavigationTest, host-наборы редактора и прежние
test-writing-tools.cjs / test-ai-visibility.cjs / test-sharing.cjs. Kotlin/Java compile.
APK и рендеры не собирались. Android Clipboard/chooser, жизненный цикл AppLock,
IME и реальные внешние приложения требуют проверки на устройстве.
