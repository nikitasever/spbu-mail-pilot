# Сведения о письме Compose

Шапка показывает отправителя, отдельный email при отличии имени, дату и время Москвы. «Сведения о письме» раскрывает To/Cc/Reply-To, Message-ID и In-Reply-To; текст можно выделить и скопировать стандартными средствами Android. Полные исходные заголовки здесь не заявляются.

NativeReaderDetails использует уже прочитанные метаданные без дополнительного запроса или изменения Seen. Роли получателей берутся только из соответствующих массивов. В старом кэше общий список помечается «без разделения»; Bcc не выводится из разницы списков. Неверные типы не преобразуются в адреса, управляющие знаки отклоняются, quoted local-part сохраняется, повторяющиеся адреса объединяются в пределах роли. Максимум 100 исходных записей на список; пропуски обозначаются текстом. Исходный JSON не изменяется.

Проверены Kotlin/Java-компиляция и шесть NativeReaderDetailsTest: роли/повторы, старый кэш, пустые авторитетные массивы, неверные типы и инъекции, quoted local-part/Reply-To, ограничение списка. Проверка на устройстве и TalkBack ещё необходима. APK и рендеры не создавались.
