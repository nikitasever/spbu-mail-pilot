# Категории и правила в Compose

Legacy: ui/mail/categories.mjs, category-dialog.mjs, category-rules.mjs;
ui/app.mjs categoryList/mailCategory/saveCategory; Java MailCategories.

Перенесены пять существующих категорий в прежнем порядке: Заявки, Ректорат,
События, Учёба, Личное. Свободное создание/удаление категорий прежний интерфейс
не поддерживал; нативный экран также редактирует фиксированные записи.
Доступны название, адреса отправителей/контактов, домены, фразы темы,
enabled/notify, сводка условий и подтверждение потери несохранённой формы.
До 40 символов названия и 1000 символов на условие; до 50 частей условия.
Никаких регулярных выражений пользователя, BODY-запросов или внешнего ИИ.

Список и reader используют Java MailCategories: точные адреса/домены,
подстроки темы без учёта регистра/NFC; OR условий и первая подходящая категория.
NativeMail хранит отдельный email для сопоставления; отображаемое имя не выдаётся
за адрес. Категории показываются отдельной полосой от фильтров прочитанности.
Фильтр явно ограничен загруженными письмами и расширяется с пагинацией.
Смена категории сбрасывает прокрутку, возврат из отдельного экрана её не сбрасывает.

NativeCategoriesModel читает/пишет общий account JSON под ReplyReminderCenter.class.
CAS сравнивает только исходную raw-запись выбранной категории: изменение соседней
категории/задач не теряется, конфликт той же категории оставляет форму открытой.
Сохраняются неизвестные поля и неизвестные категории. Сохраняемые записи полные,
порядок отображения фиксируется существующим IDS. После commit штатный NoticeCenter
читает ту же mailCategories; Android разрешения/настройки уведомлений имеют приоритет.
Отдельных настроек уведомлений/дублирующей базы нет.

Исправлен существующий случай частичной записи {id,notify}: отсутствие subjects
теперь подставляет дефолт в Java matcher, как уже делал JS categoryList. Пустая строка
subjects по-прежнему означает отсутствие условий темы. Входной объект не меняется.
При возвращении в WebView reloadNativeState обновляет категории/безопасный список
почты, сохраняя открытые формы. Сгенерированный assets/app.js обновлён build_ui.cjs.

Lifecycle: сохранённая форма остаётся в ViewModel при повороте/уходе в фон;
Bundle не содержит её текста. При уничтожении процесса несохранённый ввод не
восстанавливается. Результат другого аккаунта/поколения не применяется; сохранение
перепроверяет foreground/AppLock/аккаунт перед commit.

Проверки: NativeCategoryRulesTest, MailCategoriesTest, NativeWorkspaceTest,
test-inbox-system.cjs (включая внешний rename и сохранность формы), test-workspace.cjs;
реальный ViewModel categoryFormState в Layoutlib без рендера; Kotlin/Java compilation.
Проверены defaults/OR/приоритет/границы домена, muted-уведомления, CAS/соседние записи,
неверные условия, неизвестные данные, отмена формы и фильтр.
Фоновые Android-уведомления и реальные касания требуют проверки на устройстве.
APK/скриншоты/выпуск не создавались по указанию пользователя.
