# Почта · тест

Личный экспериментальный Android-клиент. Неофициальный проект; не продукт СПбГУ.

## Возможности

- IMAP с TLS: все папки и вся история, страницы по 50 писем, отметки прочтения на сервере.
- SMTP с TLS: отправка, ответы, To/Cc/Bcc, вложения, локальные черновики. SMTP нужно проверить с реальным сервером.
- Зашифрованное сохранение нескольких аккаунтов через Android Keystore; переключение и отдельное удаление.
- Задачи создаются вручную: письмо само по себе не поручение. Задачи, заметки и черновики разделены по аккаунтам.
- Фоновая проверка новых писем примерно раз в 15 минут; Android может задерживать её. Нужно разрешение на уведомления.
- Напоминания о задачах: за час до времени или в 09:00 Москвы для даты без времени.
- PDF/DOCX открываются через приложения телефона. Номер открывает системный набор; приложение не совершает звонок само.
- Версия 0.9.1: Настройки → Проверить обновление. Проверяются SHA-256, пакет, версия и подпись установленного приложения. Установку подтверждает пользователь в Android.

## Обновления

Исходники закрыты: https://github.com/nikitasever/spbu-mail-pilot

Публичный канал содержит только APK, метаданные и workflow публикации: https://github.com/nikitasever/spbu-mail-pilot-updates/releases/latest

Первый переход с 0.6/0.7 на 0.9.1 требует ручной установки APK или ADB. После этого новые версии доступны внутри приложения. Входы и задачи сохраняются, поскольку подпись прежняя.

GitHub Actions после push в main запускает тесты, собирает и подписывает APK, затем публикует новый номер версии в канале обновлений. Уже опубликованная версия не заменяется: для выпуска измените versionCode и versionName в AndroidManifest.xml и отображаемый номер версии в интерфейсе.

В GitHub Actions Secrets хранятся APK_KEYSTORE_BASE64, APK_STORE_PASSWORD, APK_KEY_PASSWORD и UPDATE_DEPLOY_KEY. Deploy key ограничен публичным репозиторием обновлений. Почтовые учётные данные не участвуют в сборке и не отправляются в GitHub.

## Локальная сборка

Нужны Python 3, Java 17, Node 24, Android SDK (platform android-34, build-tools 35.0.0). ANDROID_HOME указывает на SDK; Windows по умолчанию использует C:/android-sdk. Maven-зависимости фиксированы и проверяются по SHA-256; npm по package-lock.json.

```sh
python build.py --test --keystore /path/to/signing.keystore --output build/spbu-mail-pilot.apk
```

Пароли подписи: APK_STORE_PASSWORD и APK_KEY_PASSWORD, alias через APK_KEY_ALIAS (по умолчанию pilot). Существующий локальный тестовый ключ использует android. Ключ не включён в Git. Новый ключ несовместим с обновлением уже установленного приложения.

## Проверки и ограничения

Java: пагинация UID, миграция и шифрование аккаунтов, MIME-вложения, напоминания, локальный SMTP, IMAP read/unread, политика обновлений. JavaScript: интерфейс, экранирование, страницы, черновики и действия. Тесты не отправляют реальных писем и не звонят. Запуск APK не подтверждает вход в реальный ящик. Мессенджер университета и полноценный VoIP ещё не подключены.
