## Возможности

- IMAP с TLS: все папки и вся история, страницы по 50 писем, отметки прочтения на сервере.
- SMTP с TLS: отправка, ответы, To/Cc/Bcc, вложения, локальные черновики. SMTP нужно проверить с реальным сервером.
- Зашифрованное сохранение нескольких аккаунтов через Android Keystore; переключение и отдельное удаление.
- Задачи создаются вручную: письмо само по себе не поручение. Задачи, заметки и черновики разделены по аккаунтам.
- Фоновая проверка новых писем примерно раз в 15 минут; Android может задерживать её. Нужно разрешение на уведомления.
- Напоминания о задачах: за час до времени или в 09:00 Москвы для даты без времени.
- PDF/DOCX открываются через приложения телефона. Номер открывает системный набор; приложение не совершает звонок само.
- Обновления: Настройки → Проверить обновление. Проверяются SHA-256, пакет, версия и подпись установленного приложения. Установку подтверждает пользователь в Android.

## Локальная сборка

Нужны Python 3, Java 17, Node 24, Android SDK (platform android-34, build-tools 35.0.0). ANDROID_HOME указывает на SDK; Windows по умолчанию использует C:/android-sdk. Maven-зависимости фиксированы и проверяются по SHA-256; npm по package-lock.json.

```sh
python build.py --test --keystore /path/to/signing.keystore --output build/spbu-mail-pilot.apk
```

Пароли подписи: APK_STORE_PASSWORD и APK_KEY_PASSWORD, alias через APK_KEY_ALIAS (по умолчанию pilot). Существующий локальный тестовый ключ использует android. Ключ не включён в Git. Новый ключ несовместим с обновлением уже установленного приложения.

## Версия 0.10.1: отправитель и рабочие календари

В заголовке открытого письма есть «Написать отправителю»: новое письмо с заполненным адресом From. «Ответить» по-прежнему использует Reply-To и сохраняет цепочку.

Календарь → Подключить рабочий календарь. Укажите название, полную HTTPS CalDAV-ссылку конкретного календаря, его логин и пароль. Для Mail.ru используйте пароль внешнего приложения; инструкция: https://help.mail.ru/calendar-help/synchronization/thunderbird/. Поддерживаются Mail.ru и рабочие серверы, предоставляющие стандартную CalDAV-коллекцию с REPORT и раскрытием повторяющихся событий.

События сервера доступны для просмотра по месяцам и обновляются при открытии календаря или вручную. Часовой пояс отображения — Москва. Устройства без сети показывают ранее загруженные месяцы. Пароли календарей хранятся отдельно в Android Keystore/AES-GCM, подключения разделены по почтовым аккаунтам. Отключение удаляет данные подключения и кэш на телефоне, события сервера остаются. Удаление сохранённого почтового аккаунта удаляет и его подключения календарей. Локальные события и задачи не отправляются на сервер.

События рабочего календаря пока не редактируются на сервере и не получают напоминания этого приложения. Если сервер не поддерживает раскрытие повторов, синхронизация сообщает ошибку и не заменяет кэш неполным расписанием. Реальный календарь проверяется владельцем после ввода данных на телефоне; тесты используют только локальный TLS-сервер.

## Версия 0.11: почта Mail.ru

Профиль → Сменить аккаунт → Добавить аккаунт → Mail.ru. Введите полный адрес и пароль внешнего приложения с доступом к Почте. IMAP imap.mail.ru:993 и SMTP smtp.mail.ru:465 используют TLS и выбираются автоматически. Ручные настройки SMTP остаются доступны.

Для календаря Mail.ru на компьютере наведите курсор на название календаря слева, нажмите ⋯ и прокрутите окно до «Синхронизация через CalDAV». На телефоне можно попробовать версию сайта для ПК. Введите ссылку коллекции и отдельный пароль с доступом к Календарю в приложении. Обычная ссылка /month/today/ не является адресом синхронизации.

## Версия 0.12: поиск календарей

Календарь → Подключить рабочий календарь → Mail.ru — найти календари. Сервер calendar.mail.ru заполнен автоматически. Введите полный адрес ящика и пароль внешнего приложения с доступом к Календарю, нажмите Продолжить и выберите календарь. Для другого сервера введите его HTTPS-адрес; ручное подключение полной CalDAV-ссылкой сохранено. Каждый календарь добавляется отдельно.

Поиск использует стандартные PROPFIND: /.well-known/caldav, current-user-principal, calendar-home-set и список коллекций. Адреса берутся из ответов сервера, без идентификаторов конкретного пользователя. Подключение сохраняется только после выбора и успешной загрузки событий. Пароль не передаётся на другой домен/порт и не попадает в JavaScript. Общие календари доступны, если сервер предоставляет их через CalDAV; ссылки sharing-calendars.mail.ru не являются адресами синхронизации. Поддержка поиска проверена на локальном TLS-сервере; реальный доступ Mail.ru требует проверки владельцем на телефоне.

## Версия 0.14: повторы и быстрый выбор ящика

При получении нераскрытых серий CalDAV приложение локально рассчитывает RRULE для выбранного месяца через lib-recur, учитывает RDATE, EXDATE, EXRULE и перенесённые/отменённые RECURRENCE-ID. Поддерживаются часовые пояса, COUNT/UNTIL и длительность. Нестандартные изменения RANGE и RDATE VALUE=PERIOD пока сообщают явную ошибку вместо неполного расписания. Проверки используют вымышленные события, в том числе настоящий TLS REPORT с нераскрытой серией. Реальный календарь Mail.ru проверяет владелец на телефоне.

Нажмите имя текущего ящика сверху: откроется список сохранённых аккаунтов с отметкой текущего, добавлением нового и управлением. Выбор другого ящика подключает его без промежуточного выхода и без повторного ввода сохранённого пароля; черновик предварительно сохраняется. На формах входа и календаря есть «Показать пароль», по умолчанию пароль скрыт. Защита скриншотов на формах пароля сохраняется. Стрелки и название месяца размещены в одной строке.

## Версия 0.14.1: диагностика входа

При отказе входа показывается ответ подключения, а не только общая ошибка. Пароль, адрес и закодированные данные авторизации скрываются. Ошибка при выборе сохранённого ящика остаётся в диалоге; сохранённые данные не удаляются. Успешный вход в реальный Mail.ru проверяет владелец на телефоне.

## Версия 0.14.2: временная недоступность почты

Ответ Service temporarily unavailable и код UNAVAILABLE показываются как временный отказ сервиса, даже если JavaMail передал AuthenticationFailedException. Подсказка о правах пароля при таком ответе не показывается. Ответ не подтверждает неверный пароль или общую аварию Mail.ru.

## Версия 0.15: календарь и свои задачи

Сетка месяца с выбором дня, отметкой сегодняшней даты, индикаторами событий и задач и повесткой выбранного дня. Подключённые календари находятся в раскрывающемся блоке. Из календаря можно создавать задачи с выбранной датой, временем и комментарием, изменять и завершать их. Задачи сохраняются на телефоне в текущем аккаунте, доступны в разделе «Задачи» и используют существующие напоминания; в Mail.ru они не отправляются. Подключённые события доступны для просмотра.

## Версия 0.16: окно дня и список писем

По нажатию на число открывается модальное окно с прокручиваемым списком дел и созданием задачи или события. Закрытие: крестик, нажатие снаружи, Escape и Android Back. После сохранения задачи возвращается окно дня. Обновлён список почты: компактные строки, цветные инициалы, группы по дате, время, отметка непрочитанного и вложения из уже открытых писем. Исправлена перерисовка формы до её отправки при реальном нажатии кнопки «Сохранить» или «Отправить»; браузерные тесты проверяют реальные клики с тестовым мостом, без реальных писем.

## Версия 0.17: поиск, сохранение и задачи

Письма ищутся сервером в полной истории выбранной папки по теме, отправителю и тексту. В «Файлах» доступны вложения писем выбранной папки: поиск по имени автоматически проверяет историю порциями по 50 писем и показывает прогресс; большой ящик требует времени. Файлы и письма (.eml) сохраняются через системный выбор места Android; максимум 100 МБ на документ. MIME-индекс не скачивает содержимое файлов. Метки «Срочно», «Важно», «Ответить» сохраняются на телефоне в текущем аккаунте, ключ включает папку и UIDVALIDITY. Задачи имеют поиск, приоритеты и фильтры выполнения. «Сохранить» теперь явное действие, считывающее поля перед записью; обновления дат и приоритетов обрабатываются через change, а ошибки показываются рядом с кнопкой. Задачи восстанавливаются после повторного открытия. Физическая проверка системного сохранения на S23 выполняется владельцем; тесты не обращаются к реальным ящикам.

## Версия 0.18: быстрые действия и написание писем

Удержание строки письма 550 мс открывает выбор «Важно», «Срочно», «Ответить», «Убрать метку» без открытия письма и изменения прочитанности. Движение отменяет удержание; доступен также контекстный вызов мышью или Shift+F10. В новом письме кнопка вложений находится у заголовка; системный выбор поддерживает несколько файлов. «Скачать» сохраняет вложение в Download/Рабочая почта через MediaStore на Android 10+; незавершённые записи удаляются при ошибке. На Android 8/9 используется выбор места. «Сохранить в…» и открытие вложения доступны отдельно.

Светлая, тёмная и системная темы сохраняются в настройках текущего аккаунта. Системный режим использует настройку Android, обновляется при возвращении в приложение; в браузере следует prefers-color-scheme. Пользовательские шаблоны сохраняются в текущем ящике на телефоне, доступны для изменения и удаления, вставляются в конец черновика, сохраняя написанное.

Без API-ключа помощь ИИ работает через подготовку редактируемого запроса и явную передачу в выбранное пользователем приложение Android либо копирование. Проверка использует черновик; предложение ответа также включает текст исходного письма, если ответ начат из открытого письма. Полный запрос виден перед передачей; вложения не включаются. Приложение не обращается к ИИ-серверу и не выполняет самостоятельную проверку: пользователь отправляет запрос в выбранном сервисе и вставляет результат вручную. Письмо не отправляется автоматически. Системное меню передачи, буфер обмена и запись в MediaStore требуют проверки владельцем на телефоне. Автотесты используют вымышленные письма и мост.

## Версия 0.19: оформление и исправления интерфейса

Единая таблица цветов и размеров вместо накопленных переопределений CSS: чёткий заголовок, круглый аватар, читаемые строки почты, спокойные поверхности полей, выделенное действие «Написать», сегменты задач и компактная нижняя навигация. Календарь сохраняет знакомую сетку, окно дня и быстрые меню открываются снизу на телефоне. Светлая/тёмная темы покрывают поля, календарь, аватары и диалоги. Проверены ширины 320/360/393/412, длинные тексты и отсутствие горизонтального сдвига; скриншоты используют вымышленные данные.

Папка поиска файлов больше не меняет выбранную папку почты. Ошибка записи откатывает завершение и удаление задач/заметок/событий и изменения настроек. Закрытие, выход, переходы и Android Back удерживают черновик на экране, если его не удалось сохранить. Вложения черновика удаляются только после успешного сохранения изменения. После успешной отправки и неудачной очистки черновика показывается предупреждение о проверке «Отправленных». Фоновая загрузка папок и ошибки списка не заменяют поле поиска во время ввода; поздний ответ о прочтении письма не перерисовывает другие разделы. Проверка реальной почты и системных действий Android остаётся на устройстве владельца.

## Версия 0.25: единое оформление окон Android

Смена аккаунта использует строки с аватаркой, адресом, названием сервиса и отметкой текущего ящика вместо стандартного текстового списка. Единая светлая/тёмная тема применяется к экрану входа, управлению аккаунтами, настройкам отправки, подключению календаря, подтверждениям и обновлению. Явная тема имеет приоритет над системной; последняя тема сохраняется для экранов вне ящика. Панели Android также следуют теме. Закрытие выбора аккаунта убирает сообщение «Открытие списка аккаунтов…». Поля ввода растут при увеличенном системном шрифте; форма SMTP прокручивается при открытой клавиатуре. Данные входа и правила переключения сохранены. Политика выбора темы и подписи сервисов проверена на тестовых данных; внешний вид нативных окон требует проверки на S23.

## Версия 0.29: передача писем и документов

В открытом письме нажмите «Поделиться текстом», у вложения или в разделе «Файлы» — «Поделиться». Android предложит совместимые приложения, включая MAX, если он установлен и принимает этот формат. Получателя и отправку вы подтверждаете в выбранном приложении. Сохраняются возможности 0.25; обновление устанавливается поверх текущей версии.

## Исходники стилей

Стили редактируются в `ui/styles/`, порядок сборки — `ui/styles/order.json`. После изменения выполните `npm run build:styles` и включите обновлённый `assets/app.css` в коммит. Android-сборка собирает его автоматически; тесты проверяют актуальность. [Порядок работы и владельцы модулей](docs/ui-architecture.md).

## Исходники JavaScript

UI редактируется в `ui/app.mjs` и тематических `.mjs`-модулях. После изменений выполните `npm run build:ui` и включите сгенерированный `assets/app.js` в коммит. Сборка Android теперь требует Node.js/npm и автоматически собирает JavaScript. [Границы модулей и команды](docs/ui-architecture.md).
